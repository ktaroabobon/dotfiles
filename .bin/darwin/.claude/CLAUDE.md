# 共通の原則

すべてのリポジトリに効く。リポジトリに AGENTS.md / CLAUDE.md があれば、そちらが優先する。

- 部分ではなく全体で考える。変更が構造・責務の境界・運用のどこに効くかを見てから手を入れ、目の前の 1 か所だけを整える変更をしない
- 足すより減らす。既存の仕組みに乗せ、今必要なものだけを作る
- 検査（lint・テスト・CI）が落ちたら、検査を緩めずにコードを直す
- 秘密の値は、コード・ログ・出力・コミットのどこにも載せない
- 取り返しのつかない操作と、方針の決まっていない分岐は、推測で進めずに聞く。聞くときは選択肢に推奨を添える
- 完了と言う前に、実際に動かして確かめる

Claude Code の Bash は hook で rtk 経由に書き換わり、出力が要約される。生の出力が要るときは `rtk proxy <cmd>`。
